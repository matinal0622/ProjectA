| Use Case | 名称 | 主要功能 |
|---|---|---|
| **UC1** | 库存管理（Stock Management） | 添加商品、增加或减少库存、删除商品、查询库存 |
| **UC2** | 会员管理（Membership Management） | 注册和查询会员，提供会员折扣及积分 |
| **UC3** | 顾客购买记录（Customer Purchase Records） | 记录顾客购买的商品、数量和金额，查询购买历史 |
| **UC4** | 报告系统（Reports） | 显示当前库存、销售额等汇总信息 |
| **UC5** | 商品折扣管理（Product Discount Management） | 添加、修改或取消某个商品的折扣 |
| **UC6** | 供应商管理（Supplier Management） | 添加、修改、删除和查询供应商信息 |
