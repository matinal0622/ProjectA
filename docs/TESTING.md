## 编译与运行

在项目根目录运行：

```sh
mkdir -p bin
javac --release 17 -encoding UTF-8 -Xlint:all -d bin src/*.java tests/ChocolateShopTest.java
java -cp bin ChocolateShopTest
java -cp bin ChocolateShop < tests/console-smoke.in
java -cp bin ChocolateShop < tests/invalid-input.in
```

本次自动测试结果：Passed 108 checks. Failed 0 checks. 编译无警告。
恢复原版 In 后，另运行了 36 个菜单检查场景，覆盖空输入、字母、负数、超长数字、金额小数位、重复小数点、大小写和下架确认，全部通过。In.java 与本地 Week 1 课堂示例逐行比较一致。
测试程序使用普通 if 和计数器打印结果；查看 Failed 是否为 0，不仅看进程退出码。

## 自动检查

- 黑巧克力与牛奶巧克力子类、初始演示数据。
- 上架、重名拒绝、空名称、非法重量/可可比例/数量/价格。
- 增加库存、减少库存、减少到零、不足库存、数量上限、失败时不改数据。
- 下架时同时移除当前商品、库存和价格；下架后不能继续增减；可以重新上架同名商品。
- 会员注册、重复编号、空字段、电话首位零、会员查询。
- 会员九折、商品折扣叠加、进价下限、单价四舍五入。
- 实付每满 $1 积 1 分、重复合法付款累计、不足 $1 的部分不跨笔累计。
- 负数、NaN、Infinity、积分上限等无效输入被拒绝。
- 查询价格不改库存、不加分；库存调整与下架不改变会员积分。

## 终端场景

console-smoke.in：注册会员，上架 Hazelnut Chocolate（8 件），加 4 件成为 12，减 2 件成为 10，查询；先 N 取消下架，再 Y 确认下架；查询全部库存，返回主菜单查询会员，积分仍为 0。

invalid-input.in：非数字、越界菜单、空会员操作、重复上架、未知商品、非数字或负数数量、库存不足、空输入取消下架、无效金额、重复会员编号。表单格式错误会返回库存菜单，不保存失败商品；不再在同一字段上循环重试。

In.java 已恢复课堂原版；不再支持旧版本的输入结束标记和自动退出。之前的 41 个输入中断测试不适用于当前版本。请使用主菜单 3 退出；直接关闭输入流可能产生原版 Scanner 的输入异常。退出不保存本次数据。
